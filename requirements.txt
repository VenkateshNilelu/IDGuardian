# --- Semantic layer (SBERT) at SERVE time only ---
# app.py encodes text with a plain AutoTokenizer + onnxruntime.InferenceSession
# (see its semantic-layer comment) instead of the sentence-transformers/torch
# wrapper -- sentence-transformers hard-imports torch the moment it's imported,
# even just for AutoTokenizer, which alone costs ~250MB RSS before any model is
# loaded and was OOM-killing this app on Render's 512MB free tier. The
# hand-rolled encode path was verified to match sentence-transformers' own
# .encode() output to ~1e-8 (floating point noise). torch/sentence-transformers
# are NOT needed to serve requests -- only to retrain (see requirements-train.txt).
